# Student Data Analysis System 

A complete data analysis project built with Python.

## Tools Used
- Python 3
- NumPy — mathematical analysis
- Pandas — data management
- Matplotlib — data visualization

## Features
- Complete student dataset management
- Statistical analysis with NumPy
- Data filtering with Pandas
- Grade assignment system
- 3 types of charts — Bar, Pie, Line
- Export data to CSV file

## Charts Generated
- Bar Chart — marks comparison
- Pie Chart — grade distribution
- Line Chart — before and after bonus marks
